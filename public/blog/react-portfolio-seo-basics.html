A Beginner’s Guide to Making a React Portfolio Easier to Find on Google

By Abidur Rahman Rafi · Beginner guide

A portfolio can look polished and still be difficult for search engines to understand. Search engine optimization (SEO) starts with clear page information, useful content, and making sure crawlers can access the site. It does not guarantee a ranking or immediate traffic, but it gives search engines better signals.

1. Write a clear page title and description

Give your homepage a unique title that explains who you are and what you do. Add a short, accurate meta description that summarizes the page. Avoid repeating the same keywords unnaturally; write for people first.

<title>Abidur Rahman Rafi | Web Developer</title>
<meta name="description" content="Portfolio showcasing web development projects, React applications, and digital experiences by Abidur Rahman Rafi.">

2. Use the correct canonical URL

A canonical link tells search engines which URL should be treated as the preferred version of a page. Use the real, public URL for that page and keep it consistent with internal links and your sitemap.

3. Add a sitemap and robots.txt

A sitemap lists important public URLs you want search engines to discover. A robots.txt file can point crawlers to that sitemap. Neither file forces Google to index a page, and the sitemap should only list pages that actually exist and are intended to be public.

4. Publish genuinely useful articles

Write tutorials that solve real problems you have tested, such as fixing a React error, deploying a Vite project, or explaining a JavaScript concept with a working example. Include your own screenshots or code where helpful, explain the solution clearly, and keep each article focused on one search intent. Avoid thin, copied, or mass-produced pages.

5. Verify the site in Google Search Console

  1. Add and verify your website property in Google Search Console.
  2. Submit https://md-abidur-rahman.vercel.app/sitemap.xml.
  3. Use URL Inspection to check whether the homepage and each article can be indexed.
  4. Review indexing reports and search performance periodically.

6. Keep the experience fast and accessible

Use descriptive headings, meaningful link text, alt text for informative images, readable mobile layouts, and compressed images. Check that navigation links work and that the main content remains useful even when third-party scripts are blocked.

Important: SEO results take time and are not guaranteed. Do not buy fake traffic, use bots, click your own ads, or ask visitors to click ads. These activities can invalidate advertising traffic and risk account restrictions.
